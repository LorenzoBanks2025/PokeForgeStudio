# Changelog

All notable changes to PokéForge Studio will be documented in this file.

## [1.0.0] - 2026-10-16
### Added
- Monorepo architecture with `pokedcomp`, `pokecompiler`, and `pokeview`.
- Support for both Pokémon Emerald (pokeemerald) and Pokémon FireRed (pokefirered).
- In-browser GBA ROM decompiler and starter project generator.
- Map Editor, Tile Palette, Collision Editor, and Event/Warp editor.
- Wild Encounters, Pokémon Dex with Radar Stats, Trainer Roster & Party Editor, Shop Inventories, and Hex Inspector.
- Rom Integrity Checker & Pre-Flight Validation service.
- Recompiler for playable GBA ROM binaries, Pret C source trees, and offline HTML5 standalone bundles.
- WebAssembly-based in-browser GBA Emulator player with sound and turbo mode.
