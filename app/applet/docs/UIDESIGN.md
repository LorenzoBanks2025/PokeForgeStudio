# UI Design System (UIDESIGN.md)

## Design Principles
- **Dark Mode Studio Palette**: Tailored slate/zinc dark theme (`slate-950`, `slate-900`, `indigo-600`) optimized for professional game development studios.
- **Typography**: Plus Jakarta Sans for headings, DM Sans for body copy, JetBrains Mono for hex offsets and code scripts.
- **Visual Feedback**: Real-time validation badges, toast notifications, and interactive radar charts.
